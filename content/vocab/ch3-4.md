## 2. เวลา

### 2.1 คำบอกเวลาและคำเชื่อม

| โรมาจิ | ความหมาย |
| :-- | :-- |
| ima | ตอนนี้ |
| ..ji | ...โมง |
| ..fun / pun | ...นาที |
| han | ครึ่ง (เช่น yo-ji han = สี่โมงครึ่ง) |
| gozen | ก่อนเที่ยง (am.) |
| gogo | หลังเที่ยง (pm.) |
| ..kara | จาก... / ตั้งแต่... |
| ..made | ถึง... |
| ..kara..made | จาก/ตั้งแต่...ถึง... |
| chōdo + เวลา | ...ตรง (chōdo yo-ji = สี่โมงตรง) |
| daitai + เวลา | ประมาณ...โมง (daitai ichi-ji) |
| mō sugu + เวลา | กำลังจะ...โมง (mō sugu san-ji) |
| เวลา + sugi | ...โมงกว่า (ni-ji sugi) |

### 2.2 บอกเวลา

#### ชั่วโมง (..ji): จำ 3 ตัวที่ผิดปกติ

| 1 | 2 | 3 | 4 | 5 | 6 |
| :-: | :-: | :-: | :-: | :-: | :-: |
| ichi-ji | ni-ji | san-ji | **yo-ji** | go-ji | roku-ji |

| 7 | 8 | 9 | 10 | 11 | 12 |
| :-: | :-: | :-: | :-: | :-: | :-: |
| **shichi-ji** | hachi-ji | **ku-ji** | jū-ji | jū ichi-ji | jū ni-ji |

> เคล็ดจำ: 4 = **yo**-ji (ไม่ใช่ yon-ji), 7 = **shichi**-ji (ไม่ใช่ nana-ji), 9 = **ku**-ji (ไม่ใช่ kyū-ji)

#### นาที (..fun / ..pun): ตัวที่เป็น **pun** ต้องจำ

| นาที | โรมาจิ | | นาที | โรมาจิ |
| :-: | :-- | :-: | :-: | :-- |
| 1 | **ip-pun** | | 7 | nana-fun |
| 2 | ni-fun | | 8 | **hap-pun** |
| 3 | **san-pun** | | 9 | kyū-fun |
| 4 | **yon-pun** | | 10 | **jup-pun** |
| 5 | go-fun | | 30 | **sanjup-pun** (= han) |
| 6 | **rop-pun** | | 100 | **hyap-pun** |

> หลักการ: นาทีที่ลงท้ายด้วย 0 (10, 20, 30...) ใช้ **-jup-pun** เช่น gojup-pun (50 นาที, อยู่ในบทสนทนา)
> นาทีอื่น เช่น 45 อ่านว่า **yonjū go-fun** (ลงท้าย 5 ใช้ fun)

#### ก่อนเที่ยง/หลังเที่ยง

| 9.00 น. | 21.00 น. |
| :-: | :-: |
| Gozen ku-ji | Gogo ku-ji |

### 4.3 บทสนทนาในสไลด์

**สมิธถามเวลาและเวลาเปิดห้าง**

- Sumisu: Sumimasen, ima nan-ji desu ka.
- Onna no hito: Ku-ji gojuppun desu.
- Sumisu: Depāto wa nan-ji kara desu ka.
- Onna no hito: Jū-ji kara desu.
- Sumisu: Nan-ji made desu ka.
- Onna no hito: Gogo hachi-ji made desu.
- Sumisu: Arigatō gozaimasu.
- Onna no hito: Dō itashimashite.

**ซาซากิถามเวลาที่ลอนดอน**

- Sasaki: Nakamura-san, ima nan-ji desu ka.
- Nakamura: 4-ji han desu.
- Sasaki: Rondon wa ima nan-ji desu ka.
- Nakamura: Gozen 8-ji han desu.
- Sasaki: Sō desu ka. Dōmo arigatō.

**ซื้อของที่ร้าน**

- Mise no hito: Irasshaimase.
- Sumisu: (ชี้) Sore o misete kudasai.
- Mise no hito: Hai, dōzo.
- Sumisu: Arigatō. Kore wa ikura desu ka.
- Mise no hito: Sanzen-en desu.
- Sumisu: (ชี้) Sore wa ikura desu ka.
- Mise no hito: Kore mo sanzen-en desu.
- Sumisu: Ja, sore o kudasai.
- Mise no hito: Hai, arigatō gozaimasu.

**จ่ายด้วยบัตร**

- Sumisu: Kore o kudasai.
- Mise no hito: 4,300-en desu.
- Sumisu: Kādo demo ii desu ka.
- Mise no hito: Hai, kekkō desu.

**ถามราคากล้องวิดีโอ**

- Sumisu: Sumimasen. Are wa bideo-kamera desu ka.
- Mise no hito: Iie, dejikame desu.
- Sumisu: Sore wa bideo-kamera desu ka.
- Mise no hito: Hai, sō desu.
- Sumisu: Ikura desu ka.
- Mise no hito: 50,000-en desu.
- Sumisu: Ja, sore o kudasai.
