| รูปประโยค | ตัวอย่าง |
| :-- | :-- |
| `[ของ] o [จำนวน] kudasai.` | Sore o futatsu kudasai. (ขออันนั้น 2 อัน) |
| ของทั่วไป ใช้ hitotsu... | Ringo o futatsu kudasai. (ขอแอปเปิ้ล 2 ลูก) |

## 4. ไป มา กลับ และการผันกริยา

### 4.1 รูปประโยคที่ใช้กับ ikimasu / kimasu / kaerimasu

| รูปแบบ | ความหมาย | ตัวอย่างในสไลด์ |
| :-- | :-- | :-- |
| `[สถานที่]` + **ni** ikimasu | ไปที่... | Sumisu-san wa ashita ginkō ni ikimasu. |
| `[สถานที่]` + **ni** kimasu | มาที่... | Chan-san wa kyonen Nihon ni kimashita. |
| `[สถานที่]` + **ni** kaerimasu | กลับที่... | Sumisu-san wa rainen Amerika ni kaerimasu. |
| N + **to** | กับ... | Chan-san wa kinō tomodachi to resutoran ni ikimashita. |
| **hitori de** | คนเดียว | hitori de ikimasu / hitori de kimasu / hitori de kaerimasu |

### 4.2 การผันกริยา

| รูป | ปัจจุบัน / อนาคต | อดีต |
| :-- | :-- | :-- |
| บอกเล่า | **-masu** | **-mashita** |
| ปฏิเสธ | **-masen** | **-masendeshita** |

| กริยา | -masu | -masen | -mashita | -masendeshita |
| :-- | :-- | :-- | :-- | :-- |
| iki- (ไป) | ikimasu | ikimasen | ikimashita | ikimasendeshita |
| ki- (มา) | kimasu | kimasen | kimashita | kimasendeshita |
| kaeri- (กลับ) | kaerimasu | kaerimasen | kaerimashita | kaerimasendeshita |

| รูป | ความหมาย |
| :-- | :-- |
| ikimasu | ไป |
| ikimasen | ไม่ไป |
| ikimashita | ได้ไป |
| ikimasendeshita | ไม่ได้ไป |

> เคล็ดจำ: ตัดท้าย -masu ออกจะได้รากกริยา (iki, ki, kaeri) แล้วเติม -masu / -masen / -mashita / -masendeshita
